# 小米商城 - 前端项目

## 📖 项目简介

这是一个模仿小米商城风格的前端电商项目,项目展示了商品导航、轮播图展示、商品分类等核心电商功能。

## 🎯 项目功能

### 1. 导航栏模块
- **黑色导航栏**：包含用户注册、登录、购物车、消息发送等快捷入口
- **白色导航栏**：展示品牌Logo、商品分类导航、搜索框
- **悬停下拉菜单**：鼠标悬停时展示分类商品预览，支持横向排列展示
- **购物车功能**：显示购物车状态，悬停时展示购物车信息

### 2. 轮播图模块
- **自动播放**：每3秒自动切换一张轮播图
- **手动切换**：点击底部指示器可切换到指定图片
- **悬停暂停**：鼠标悬停时暂停自动播放，离开后恢复
- **平滑过渡**：图片切换时带有平滑的动画效果

### 3. 商品分类模块
- **数码分类**：展示蓝牙音箱、蓝牙耳机、手环、平板等数码产品
- **服饰分类**：展示T恤、卫衣、外套等服饰产品
- **食品分类**：展示零食、茶叶等食品产品
- **商品卡片**：每个商品包含图片、名称、价格信息

### 4. 商品详情模块
- **商品展示**：展示商品大图和详细信息
- **价格显示**：突出显示商品价格
- **购买入口**：提供购物车添加功能（待实现）

## 🚀 快速开始

### 1. 下载或克隆项目
```bash
# 如果项目托管在Git平台，可以使用：
git clone [项目地址]
```

### 2. 打开项目
直接在浏览器中打开 `导航栏.html/index.html` 文件即可预览。

### 3. 推荐使用本地服务器访问
```bash
# 如果安装了Python 3
python -m http.server 8000

# 如果安装了Node.js
npx http-server -p 8000
```

然后在浏览器中访问：`http://localhost:8000/导航栏.html/index.html`

## 🎨 设计规范

### 配色方案
- **主色调**：浅黄色系 `#fff9e6`
- **强调色**：橙黄色 `#f5c878`、`#f5b752`
- **背景色**：白色 `#ffffff`
- **文字色**：深灰色 `#333333`

### 布局特点
- **固定宽度**：1226px（适配桌面端）
- **响应式**：部分元素支持自适应
- **悬停效果**：商品卡片悬停时上移并显示阴影
- **动画过渡**：所有交互都带有平滑过渡效果

### 交互规范
- 所有可点击元素都有悬停状态反馈
- 轮播图支持自动播放和手动控制
- 下拉菜单展开时有平滑动画
- 商品图片悬停时放大显示
